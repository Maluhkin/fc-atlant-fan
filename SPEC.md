# ТЗ — Фан-приложение футбольного клуба

Статус: MVP реализован и проверен 20.10.2026 · см. DEV-JOURNAL.md

## Цель
Мобильное приложение для болельщиков клуба: ближайший матч, календарь и результаты,
турнирная таблица, состав, новости, билеты. Запускается на телефоне как обычное
приложение с иконкой на домашнем экране.

## Пользователь
Болельщик клуба. Открывает перед матчем/после матча, смотрит счёт, календарь,
новости. Не регистрируется, данных не вводит.

## Что входит в MVP (5 экранов)
1. **Главная** — обратный отсчёт до ближайшего матча, карточка последнего результата,
   новость дня, быстрые ссылки.
2. **Матчи** — календарь предстоящих + прошедшие с результатами, фильтр «дома/в гостях».
3. **Таблица** — турнирная таблица (место, И, В, Н, П, мячи, О), подсветка своей команды.
4. **Состав** — игроки по линиям: номер, имя, амплуа, возраст, фото-заглушка с инициалами.
5. **Новости** — лента карточек с датой и текстом; открытие новости на весь экран.

Плюс: экран «Билеты» — выбор матча и кнопка покупки (ссылка на внешнюю кассу, без
платежей внутри приложения).

## Стек
- **PWA**: HTML + CSS + JavaScript без фреймворков, без сборки, без node_modules.
- Данные — один файл `js/data.js` (клуб, цвета, матчи, таблица, состав, новости).
- Установка на телефон: `manifest.webmanifest` + service worker (офлайн-кэш).
- Идентичность клуба (название, город, цвета, логотип-заглушка) — переменные в `data.js`.
- Язык интерфейса: русский.
- Тёмная тема по умолчанию, мобильный вёрстка-first (базовая ширина 390 px).

## Критерий приёмки
1. Открывается на телефоне по адресу из локальной сети, без ошибок в консоли.
2. Все 5 экранов + билеты переключаются нижней навигацией, состояние не теряется.
3. Данные меняются правкой только `data.js` — без касания вёрстки.
4. Приложение устанавливается на домашний экран и открывается офлайн (после 1-го визита).
   *Уточнение по факту: офлайн проверен на localhost; установка с телефона требует
   публикации на HTTPS — см. этап 2 (деплой).*
5. Нет горизонтальной прокрутки на ширине 360–430 px.

## Что НЕ входит (этап 2)
Реальная оплата билетов, авторизация, push-уведомления, админка, публикация в
App Store / Google Play (обёртка Capacitor / React Native), интеграция с API лиги.

## Риски
- Настоящие данные клуба (расписание, таблица) нужно откуда-то брать — в MVP это
  ручной файл; автообновление = этап 2 с API.
- Публикация в сторах требует аккаунтов разработчика ($25 Google / $99 Apple) —
  PWA ставится без них.
