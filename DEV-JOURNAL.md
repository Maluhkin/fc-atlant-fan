# Журнал разработки — ФК «Атлант» (фан-приложение)

## Статус: MVP готов и проверен (20.10.2026)

Папка проекта: `C:\Users\reyze\projects\fc-fan-app`
ТЗ: `SPEC.md`

## Что сделано

- 6 экранов: Главная, Матчи, Таблица, Состав, Новости (+ статья), Билеты.
- Нижняя навигация на 5 вкладок, hash-маршрутизация (`#home`, `#news/n5`, …).
- Обратный отсчёт до ближайшего матча, обновляется каждую секунду.
- Все данные клуба — в `js/data.js`, вёрстка от данных не зависит.
- Время матчей форсировано в `Europe/Moscow` через `Intl` — не зависит от пояса телефона.
- PWA: манифест, иконки 192/512/maskable, service worker
  (страницы — network-first, ассеты — stale-while-revalidate), офлайн-проверено.
- Локальный сервер без зависимостей (`server.js`), запуск в один клик (`start.cmd`).

## Принятые решения

- **PWA, а не React Native.** Нулевые зависимости, работает сразу, ставится на
  домашний экран. Обёртка в сторы (Capacitor) — этап 2, если понадобится.
- **Без сборщика и фреймворков.** Файл `data.js` правится без пересборки.
- **Иконки нарисованы скриптом** `tools/make-icons.ps1` (System.Drawing), без внешних ассетов.
- **Проверка вёрстки — измерения, а не «на глаз»**: `tools/cdp-check.js` поднимает
  headless-Edge через CDP (свой минимальный WebSocket-клиент, Node 20 без зависимостей).

## Свидетельства проверки (20.10.2026)

`node tools/cdp-check.js`:

- 7 маршрутов: 5 вкладок на всех, переполнение по ширине — 0;
- ширина документа 390 и 360 px — без горизонтальной прокрутки;
- ошибок в консоли — 0;
- офлайн (Network.emulateNetworkConditions offline + reload): отрисованы hero,
  5 вкладок, 3 карточки новостей — кэш работает;
- время на экране: `25 окт, вс · 19:00` (пояс клуба, не машины UTC+7).

Найденные и исправленные дефекты:

1. Время показывалось в поясе системы (+7) — исправлено `Intl` + `timeZone`.
2. Stale service worker отдавал старый JS при правках — стратегия заменена на
   network-first + stale-while-revalidate.
