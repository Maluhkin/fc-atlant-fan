# ФК «Атлант» — приложение болельщика

Мобильное приложение (PWA) для болельщиков футбольного клуба: ближайший матч,
календарь и результаты, турнирная таблица, состав, новости, билеты.
Работает в браузере телефона, ставится на домашний экран, открывается офлайн.

## Запуск

Двойной клик по **`start.cmd`** — поднимется локальный сервер и покажутся два адреса:

- `http://localhost:4173` — на этом компьютере;
- `http://<IP>:4173` — с телефона в той же Wi-Fi сети.

Или вручную: `node server.js` (порт меняется переменной `PORT`).

## Как поменять данные клуба

Всё содержимое — в одном файле **`js/data.js`**:

| Что | Где |
|---|---|
| Название, город, лига, сезон, инициалы на эмблеме | `CLUB` |
| Цвета (синий/акцент) | `CLUB.colors.primary`, `CLUB.colors.accent` |
| Часовой пояс показа времени | `CLUB.timezone` |
| Ссылка на кассу билетов | `CLUB.ticketsUrl` |
| Матчи (даты, соперники, счёт) | `MATCHES` |
| Турнирная таблица | `TABLE` (у своей команды `isUs: true`) |
| Состав по линиям | `SQUAD` |
| Новости | `NEWS` |

Формат даты матча: `'2026-10-25T19:00:00+03:00'`, статус — `upcoming` или
`finished` (для прошедших обязательны `scoreHome` и `scoreAway`).
Время на экране всегда показывается в поясе клуба (`CLUB.timezone`), а не телефона.

После правки данных увеличьте `VERSION` в `sw.js` (например `fc-atlant-v2` → `v3`),
чтобы у установленных приложений обновился кэш.

## Структура

```
index.html            каркас и нижняя навигация
css/style.css         оформление, тёмная тема
js/data.js            ← все данные клуба
js/app.js             экраны, маршруты, обратный отсчёт
sw.js                 офлайн-кэш и автообновление
manifest.webmanifest  имя, иконки, режим приложения
icons/                иконки 192/512 + maskable
server.js             локальный сервер без зависимостей
tools/                make-icons.ps1 (иконки), cdp-check.js (проверка вёрстки)
```

## Установка на телефон

- **iPhone (Safari):** «Поделиться» → «На экран "Домой"».
- **Android (Chrome):** меню → «Установить приложение».

Полноценная установка с офлайн-режимом требует **HTTPS**, поэтому с телефона
удобнее после публикации на хостинге. По локальной сети (`http://IP:4173`)
приложение открывается, но офлайн-кэш и установка могут быть недоступны —
это ограничение браузера, а не приложения.

## Проверка

```
node tools/cdp-check.js
```

Прогоняет все экраны в headless-Edge на 390 и 360 px, проверяет переполнение,
активные вкладки, консольные ошибки и офлайн-режим.
Отчёт: `shots/layout-report.json`.
